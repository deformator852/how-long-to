# Час підльоту

Фронтовое приложение (Vue 3 + Vuetify 4 + Pinia): строишь маршрут из любого числа точек — получаешь время полёта по прямым между ними при максимальной скорости (Бандероль, Герань-2, Герань-3, Герань-4, Герань-5 или своя скорость), общее и до каждой точки.

- **Маршрут** — цепочка точек в двух режимах, маршрут у них общий:
  - «Список» — поля с поиском по населённым пунктам; «Додати точку» дописывает точку в конец, крестик убирает. Под результатом — 3D-вид маршрута (`src/components/Route3D.vue`): наклонённая карта с рельефом, над ней лента полёта со стенкой до земли; высота ленты условная, для наглядности. [MapLibre GL](https://maplibre.org) + векторные тайлы [OpenFreeMap](https://openfreemap.org) + рельеф [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/), всё без ключей; MapLibre (~1,6 МБ с воркером) грузится отдельным чанком только для этого вида.
  - «Карта» — клик по карте ставит точку, отрезки рисуются стрелками с длиной в км; точки перетаскиваются, по клику на точку — название и «Прибрати». Точка с карты подписывается ближайшим пунктом (если он в пределах 15 км), иначе координатами. Карта — [Leaflet](https://leafletjs.com) + тайлы [OpenStreetMap](https://www.openstreetmap.org/copyright), грузится отдельным чанком только в этом режиме (`src/components/RouteMap.vue`).
- **Населённые пункты** — локальный справочник `public/places-ua.json` (~32 тыс. пунктов Украины), собран из [GeoNames](https://www.geonames.org) (CC BY 4.0). Показываются украинские названия; русские хранятся только как синонимы для поиска («Харьков» находит Харків). В подсказке — район и область: одноимённые сёла одной области различаются районом, а если совпадает и район, и расстояние до ближайшего города — ещё и направлением («4 км на південь від м. Вишневе»). При сборке убираются дубли GeoNames (одноимённые пункты одного района ближе 2 км) и правятся устаревшие названия районов (`DISTRICT_FIXES` в скрипте). `id` пункта — geonameid, он не меняется при пересборке.
  Пересобрать: скачать `UA.zip` и `alternatenames/UA.zip` с https://download.geonames.org/export/dump/, распаковать и запустить `python3 scripts/build_places.py <UA.txt> <alternatenames UA.txt> public/places-ua.json`.
- **Время** — `src/utils/flight.js`: расстояние по дуге большого круга ÷ макс. скорость. Пресеты скоростей там же; цифры — открытые оценки ГУР/СМИ, источник указан в описании каждого аппарата (`src/i18n.js`).
- **Язык** — только украинский; тексты интерфейса в `src/i18n.js`.

## Запуск

```sh
npm install
npm run dev
```

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает и выкладывает `dist` при пуше в `main`.
В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
`base: './'` в `vite.config.js` — работает под любым именем репозитория.

## PWA

Приложение устанавливается на телефон/ПК («Установить» / «На экран Домой») и работает офлайн:
Service Worker (`vite-plugin-pwa`, режим `autoUpdate`) кеширует сборку и справочник пунктов.
Тайлы карт берутся из сети; без сети показываются последние просмотренные (кеши `osm-tiles` для 2D и `map3d-tiles` для 3D) — заранее ничего не скачивается.
Иконки — `public/pwa-*.png`, `maskable-512x512.png`, `apple-touch-icon.png` (из `public/favicon.svg`).
