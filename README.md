# Час підльоту

Фронтовое приложение (Vue 3 + Vuetify 4): строишь маршрут из любого числа точек — получаешь время полёта по прямым между ними при максимальной скорости (Бандероль, Герань-2, Герань-3, Герань-4, Герань-5 или своя скорость), общее и до каждой точки.

- **Маршрут** — цепочка точек в двух режимах, маршрут у них общий:
  - «Список» — поля с поиском по населённым пунктам; «Додати точку» дописывает точку в конец, крестик убирает. Рядом — 3D-вид маршрута (`src/components/Route3D.vue`): на широком экране (от 1280 px) слева во всю высоту окна, на узком — под результатом: наклонённая карта с рельефом, над ней лента полёта со стенкой до земли; высота ленты условная, для наглядности. [MapLibre GL](https://maplibre.org) + векторные тайлы [OpenFreeMap](https://openfreemap.org) + рельеф [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/), всё без ключей; MapLibre (~1,6 МБ с воркером) грузится отдельным чанком только для этого вида.
  - «Карта» — клик по карте ставит точку, отрезки рисуются стрелками с длиной в км; точки перетаскиваются, по клику на точку — название и «Прибрати». Точка с карты подписывается ближайшим пунктом (если он в пределах 15 км), иначе координатами. Карта — [Leaflet](https://leafletjs.com) + тайлы [OpenStreetMap](https://www.openstreetmap.org/copyright), грузится отдельным чанком только в этом режиме (`src/components/RouteMap.vue`).
- **Цвета** — у каждого отрезка маршрута свой цвет, точка красится цветом отрезка, который в неё ведёт (старт — оранжевый); одни и те же цвета в списке, таблице, на 2D- и 3D-карте. Палитры для светлой и тёмной темы — `src/utils/routeColors.js`, зарегистрированы как цвета темы Vuetify `leg-1`…`leg-8`.
- **Населённые пункты** — локальный справочник `public/places-ua.json` (~32 тыс. пунктов Украины), собран из [GeoNames](https://www.geonames.org) (CC BY 4.0). Показываются украинские названия; русские хранятся только как синонимы для поиска («Харьков» находит Харків). В подсказке — район и область: одноимённые сёла одной области различаются районом, а если совпадает и район, и расстояние до ближайшего города — ещё и направлением («4 км на південь від м. Вишневе»). При сборке убираются дубли GeoNames (одноимённые пункты одного района ближе 2 км) и правятся устаревшие названия районов (`DISTRICT_FIXES` в скрипте). `id` пункта — geonameid, он не меняется при пересборке.
  Пересобрать: скачать `UA.zip` и `alternatenames/UA.zip` с https://download.geonames.org/export/dump/, распаковать и запустить `python3 scripts/build_places.py <UA.txt> <alternatenames UA.txt> public/places-ua.json`.
- **Время** — `src/utils/flight.js`: расстояние по дуге большого круга ÷ макс. скорость. Пресеты скоростей там же; цифры — открытые оценки ГУР/СМИ, источник указан в описании каждого аппарата (`src/i18n.js`).
- **Калькулятор** — переиспользуемый компонент `src/components/FlightCalculator.vue` (форма, результат, 2D- и 3D-карта). Состояние — экземпляр `createFlight()` из `src/composables/flight.js`, его передают пропом; компоненты внутри получают его через `useFlight()`. Экземпляров может быть сколько угодно, они независимы: на главной — один, с историей маршрутов в `localStorage` (`persistHistory: true`), на странице точности — свой у каждого примера.
- **«Наскільки точний застосунок»** (`#accuracy`, `src/components/RealCases.vue`) — реальные эпизоды атак: посты официальных каналов (Повітряні сили, КМВА) со ссылками на оригиналы и расчёт приложения для тех же точек; «Перевірити самому» открывает в примере калькулятор с этим маршрутом. Данные примеров — `src/data/realCases.js`: тексты постов дословно, время публикации в UTC, точки — `id` из справочника. Берём только эпизоды, где в районе была одна цель, и без погибших.
- **Язык** — только украинский; тексты интерфейса в `src/i18n.js`.

## Запуск

```sh
npm install
npm run dev
```

## Деплой на GitHub Pages

```sh
npm run deploy
```

Собирает проект и публикует `dist/` в ветку `gh-pages` (скрипт `scripts/deploy.sh`; ветка каждый раз перезаписывается одним коммитом — в ней только сайт). Сайт: `https://<user>.github.io/<repo>/`, обновляется через 1–2 минуты после команды.
Один раз в настройках репозитория: **Settings → Pages → Build and deployment → Source: Deploy from a branch → `gh-pages` / (root)**.
`base: './'` в `vite.config.js` — работает под любым именем репозитория.

## PWA

Приложение устанавливается на телефон/ПК («Установить» / «На экран Домой») и работает офлайн:
Service Worker (`vite-plugin-pwa`, режим `autoUpdate`) кеширует сборку и справочник пунктов.
Тайлы карт берутся из сети; без сети показываются последние просмотренные (кеши `osm-tiles` для 2D и `map3d-tiles` для 3D) — заранее ничего не скачивается.
Иконки — `public/pwa-*.png`, `maskable-512x512.png`, `apple-touch-icon.png` (из `public/favicon.svg`).
